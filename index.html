Ajuda: como navegar

Como mudar de página?

Use o menu no topo. A página em que você está fica com fundo branco e sublinhado. No fim de cada página há botões de “Anterior” e “Próxima”.

Como usar só o teclado?

Use Tab para avançar e Shift + Tab para voltar. Aperte Enter para abrir um link. O item selecionado fica com um contorno bem visível. O primeiro Tab mostra o atalho “Pular para o conteúdo”.

Como voltar ao topo da página?

Use o link “↑ Voltar ao topo” no rodapé de todas as páginas.
