Cores e tipografia

A cor organiza o conteúdo, destaca o que importa e orienta a interação. A tipografia garante que o texto seja lido sem esforço.

Responsável: Lucas Samuel dos Santos

Paleta de cores

Usamos poucas cores, cada uma com função bem definida. Todos os pares de texto e fundo têm contraste de pelo menos 4,5:1.

AaAzul#1e40afCabeçalho, links e títulos. Texto branco sobre azul: 8,72:1.
AaLaranja#b45309Somente botões de ação principal. Texto branco sobre laranja: 5,02:1.
AaGrafite#1b2333Texto corrido. Sobre branco: 15,73:1.
AaCinza-azulado#f2f5fbFundo de seções de apoio. Texto grafite sobre ele: 14,41:1.

O significado das cores

Cada cor transmite uma sensação. Escolhemos de acordo com o que o site quer comunicar.

Sensação de cada cor e uso no site
CorSensação (conforme a aula)Uso no site
AzulFrio, calma, suavidade.Cor principal: passa tranquilidade para quem lê.
LaranjaDinamismo, expansão.Chama a atenção para a ação principal.
Preto e cinzaO preto destaca as demais cores. O cinza reduz as sensações.Textos e bordas, para não competir com o azul e o laranja.
BrancoPureza, paz.Fundo geral, com bastante espaço livre.

Tipografia

Fontes sem serifa são indicadas para produtos digitais. Por isso usamos a fonte do sistema do próprio aparelho, que carrega rápido e é familiar.

Sem serifa (usada)

Interface clara, leitura fácil.

Com serifa (impressos)

Interface clara, leitura fácil.

Espaçamento fixo (código)

Interface clara, leitura fácil.

Caixa alta e caixa baixa

Textos longos em caixa alta reduzem o ritmo de leitura e parecem gritar. Todas as letras maiúsculas têm a mesma altura, o que dificulta distinguir uma da outra.

✗ Evite

Para ler este texto longo é preciso mais esforço do que o necessário.

✓ Prefira

Para ler este texto longo é preciso menos esforço.

Regras que seguimos

  • Manter o mesmo padrão de cores em todas as páginas.
  • Não usar a mesma cor para funções diferentes: o laranja é só para ações.
  • Texto corrido com 17 px, entrelinha de 1,65 e linhas curtas para descansar a vista.
  • Títulos que crescem e diminuem conforme a largura da tela.
  • Caixa alta só em palavras isoladas, nunca em parágrafos.
